# Function Name: `GetTotalSpace`

## Description
 Returns the total disk space or in-memory space available for an application.

## Return Type
`numeric`

## Syntax
```cfml
getTotalSpace(path);
```

## Arguments

### Argument: `path`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: path to the hard drive or for in memory file system.
