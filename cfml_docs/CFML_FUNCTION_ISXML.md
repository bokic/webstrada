# Function Name: `IsXML`

## Description
Determines whether a string is well-formed XML text.

## Return Type
`boolean`

## Syntax
```cfml
isXML(value)
```

## Arguments

### Argument: `value`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string containing the XML document text.

### Argument: `parserOptions`
- **Type**: `struct`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: XML parsing options. No documentation available on usage.
