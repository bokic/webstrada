# Function Name: `YesNoFormat`

## Description
 Yes, for a true value; No for a false value, empty string or null. Throws an exception for other values.

## Return Type
`string`

## Syntax
```cfml
yesNoFormat(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A Boolean value or empty string
