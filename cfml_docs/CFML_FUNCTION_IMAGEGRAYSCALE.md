# Function Name: `ImageGrayscale`

## Description
 Converts a ColdFusion image to grayscale.

## Return Type
`void`

## Syntax
```cfml
imageGrayScale(name)
```

## Arguments

### Argument: `name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The image on which this operation is performed.
