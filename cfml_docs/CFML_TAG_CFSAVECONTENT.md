# Tag Name: `cfsavecontent`

## Description
Saves the generated content of the cfsavecontent tag, including the results of evaluating expressions and executing custom tags, in the specified variable.

## Syntax
```cfml
<cfsavecontent variable="">
```

## Attributes / Variants

### Attribute: `variable`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Name of the variable in which to save the generated content of the tag.

## Limitations

- **Must be nested inside**: *None*
- **Must not be nested inside**: *None*
