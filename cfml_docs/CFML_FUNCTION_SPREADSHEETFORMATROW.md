# Function Name: `SpreadsheetFormatRow`

## Description
Formats the contents of a single row of an Excel spreadsheet object.

## Return Type
`void`

## Syntax
```cfml
spreadsheetFormatRow(spreadsheetObj, format, row)
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The spreadsheet object for which formatting will be applied

### Argument: `format`
- **Type**: `struct`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A structure containing the formatting information

### Argument: `row`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The row number for which to apply formatting
