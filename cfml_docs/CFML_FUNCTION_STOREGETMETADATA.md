# Function Name: `StoreGetMetadata`

## Description
 Returns the metadata related to the object or bucket.

## Return Type
`struct`

## Syntax
```cfml
storeGetMetadata(url);
```

## Arguments

### Argument: `url`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Amazon S3 URLs (bucket or object).

- **Coldfusion Support**: Minimum version: `9.0.1`.
