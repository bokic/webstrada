# Function Name: `UCase`

## Description
 Converts the alphabetic characters in a string to uppercase.

## Return Type
`string`

## Syntax
```cfml
uCase(String)
```

## Arguments

### Argument: `String`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string or a variable that contains one
