# Function Name: `GetLocalHostIP`

## Description
Returns the localhost IP address, which is 127.0.0.1 for IPv4 and ::1 for IPv6 addresses.

## Return Type
`string`

## Syntax
```cfml
getLocalhostIP()
```

## Arguments

This function does not take any arguments.
