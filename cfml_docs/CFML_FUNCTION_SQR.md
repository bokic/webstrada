# Function Name: `Sqr`

## Description
 Calculates the square root of a number.

## Return Type
`numeric`

## Syntax
```cfml
sqr(number)
```

## Arguments

### Argument: `number`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A positive integer or a variable that contains one.
 Number whose square root to get.
