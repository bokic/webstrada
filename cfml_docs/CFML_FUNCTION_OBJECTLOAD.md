# Function Name: `ObjectLoad`

## Description
Load object from binary object

## Return Type
`any`

## Syntax
```cfml
objectLoad(binaryObject)
objectLoad(filepath)
```

## Arguments

### Argument: `binaryObject`
- **Type**: `binary`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A binary object returned by objectSave function.

### Argument: `filepath`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A file path to a serialized object
