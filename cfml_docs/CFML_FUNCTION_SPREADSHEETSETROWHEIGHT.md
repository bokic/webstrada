# Function Name: `SpreadsheetSetRowHeight`

## Description
 Sets the height of a row in a worksheet.

## Return Type
`void`

## Syntax
```cfml
spreadsheetSetRowHeight(spreadsheetObj, rowNumber, height)
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The Excel spreadsheet object to which to set the column width.

### Argument: `rowNumber`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Specifies the row to set the height.

### Argument: `height`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Specifies the height in points.
