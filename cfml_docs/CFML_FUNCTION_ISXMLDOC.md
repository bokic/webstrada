# Function Name: `IsXmlDoc`

## Description
Determines whether a function parameter is an Extended Markup language (XML) document object.

## Return Type
`boolean`

## Syntax
```cfml
isXMLDoc(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: XML document
