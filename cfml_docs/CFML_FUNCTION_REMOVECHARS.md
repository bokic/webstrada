# Function Name: `RemoveChars`

## Description
 Removes characters from a string.

## Return Type
`string`

## Syntax
```cfml
removeChars(String, start, count)
```

## Arguments

### Argument: `String`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The string or variable containing a string to process.

### Argument: `start`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The starting position in the string to process.

### Argument: `count`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Number of characters to remove.
