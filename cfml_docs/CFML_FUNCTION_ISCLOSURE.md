# Function Name: `IsClosure`

## Description
Checks if a given object is a closure.

## Return Type
`boolean`

## Syntax
```cfml
isClosure(object)
```

## Arguments

### Argument: `object`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The object to check if it is a closure.
