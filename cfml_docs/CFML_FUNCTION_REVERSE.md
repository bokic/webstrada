# Function Name: `Reverse`

## Description
 Reverses the order of items, such as the characters in a
 string and the digits in a number

## Return Type
`string`

## Syntax
```cfml
reverse(String)
```

## Arguments

### Argument: `String`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string or a variable that contains one
