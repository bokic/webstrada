# Function Name: `Mid`

## Description
 Extracts a substring from a string.

## Return Type
`string`

## Syntax
```cfml
mid(String, start, count)
```

## Arguments

### Argument: `String`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The string from which the substring will be extracted.

### Argument: `start`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The position of the first character to retrieve.

### Argument: `count`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The number of characters to retrieve.
