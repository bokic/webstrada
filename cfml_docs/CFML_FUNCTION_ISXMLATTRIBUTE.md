# Function Name: `IsXmlAttribute`

## Description
Determines whether the function parameter is an XML Document Object Model (DOM) attribute node.

## Return Type
`boolean`

## Syntax
```cfml
isXMLAttribute(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Name of an XML attribute.
