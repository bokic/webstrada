# Tag Name: `cfloop`

## Description
Different items are required based on loop type. Items listed
 as required may not be depending on your loop type.
 Loop forms:
 [query] [condition] [index + from + to ] [index + list]
 [collection + item ]

## Syntax
```cfml
<cfloop>
```

## Attributes / Variants

### Attribute: `index`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Index value. CFML sets it to from value and
 increments or decrements by step value, until it equals to
 value.

### Attribute: `from`
- **Type**: `numeric`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Beginning value of index.

### Attribute: `to`
- **Type**: `numeric`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Ending value of index.

### Attribute: `step`
- **Type**: `numeric`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Step by which to increment or decrement the index value.

### Attribute: `condition`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Condition that controls the loop.

### Attribute: `query`
- **Type**: `query`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Query that controls the loop.

### Attribute: `group`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF10+ and Lucee4.5+. Query column to use to group sets of records. Eliminates adjacent duplicate rows when data is sorted. Use if you retrieved a recordset ordered on one or more query columns.

### Attribute: `groupcasesensitive`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: `No`
- **Description**: Lucee4.5+. Boolean indicating whether to group with regard to case or not. The default value is NO; case is considered while grouping. If the query attribute specifies a query object that was generated by a case-insensitive SQL query, set the groupCaseSensitive attribute to NO to keep the recordset intact.

### Attribute: `startrow`
- **Type**: `numeric`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: First row of query that is included in the loop.

### Attribute: `endrow`
- **Type**: `numeric`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Last row of query that is included in the loop.

### Attribute: `list`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: The list attribute is used with the `index` (or `item` in Lucee or CF2016+) attribute to loop over a list, variable, or filename; contains a list

### Attribute: `delimiters`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: `,`
- **Description**: Character(s) that separates items in list

### Attribute: `collection`
- **Type**: `any`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: The collection attribute is used with the item attribute.
 often to loop over a structure

### Attribute: `item`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: The item attribute is used with the collection attribute often to loop over a structure or array

NOTE: If you have item attribute without index, item represents the key. In Lucee4.5+ you can use item with index, but keep in mind, that item will represent the value whereas index will be the key now!

### Attribute: `array`
- **Type**: `array`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF8+ An array.

### Attribute: `characters`
- **Type**: `numeric`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF8+ The number of characters to read during each iteration of the loop from the file specified in the file attribute. 
If the value of the characters attribute is more than the number of characters in the file, 
ColdFusion uses the number of characters in the file.

### Attribute: `file`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF8+ The absolute path and filename of the text file to read, one line at a time. 
This is helpful when reading large text files, because you can reuse the value of the index variable, 
which contains the current line of the file. 
When the loop completes, ColdFusion closes the file.

### Attribute: `times`
- **Type**: `numeric`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Lucee5+ If you want to have a specific iterations you can simply use `times` param instead of `from` and `to`

## Limitations

- **Must be nested inside**: *None*
- **Must not be nested inside**: *None*
