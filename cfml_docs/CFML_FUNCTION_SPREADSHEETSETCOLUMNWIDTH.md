# Function Name: `SpreadsheetSetColumnWidth`

## Description
 Sets the width of a column in a worksheet.

## Return Type
`void`

## Syntax
```cfml
spreadsheetSetColumnWidth(spreadsheetObj, columnNumber, width)
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The Excel spreadsheet object to which to set the column width.

### Argument: `columnNumber`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Specifies the column to set the width.

### Argument: `width`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Specifies the width in points.
