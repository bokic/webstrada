# Function Name: `RestDeleteApplication`

## Description
 Unregisters the directory path if it is already registered.

## Return Type
`void`

## Syntax
```cfml
restDeleteApplication('dirPath');
```

## Arguments

### Argument: `dirPath`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Path to the directory to be unregistered. If the path is not valid, it results in an error.
