# Function Name: `SpreadsheetDeleteColumns`

## Description
 Deletes the data from multiple columns of an Excel spreadsheet object. This function does not remove the columns.

## Return Type
`void`

## Syntax
```cfml
spreadsheetDeleteColumns(spreadsheetObj, range)
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: No Help Available

### Argument: `range`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: No Help Available
