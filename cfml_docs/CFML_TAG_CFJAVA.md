# Tag Name: `cfjava`

## Description
Provides support for writing Java code within ColdFusion.

## Syntax
```cfml
<cfjava handle="classInstance">
```

## Attributes / Variants

### Attribute: `handle`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The variable that holds the value of class instance of the Java code.

## Limitations

- **Must be nested inside**: *None*
- **Must not be nested inside**: *None*
