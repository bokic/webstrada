# Function Name: `StructIsEmpty`

## Description
 Determines whether a structure contains data.

## Return Type
`boolean`

## Syntax
```cfml
structIsEmpty(structure)
```

## Arguments

### Argument: `structure`
- **Type**: `struct`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Structure to test

## Limitations and Other Info

- **Type Requirement**: The first argument must be a valid structure/associative array.
