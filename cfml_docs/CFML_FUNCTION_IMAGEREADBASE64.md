# Function Name: `ImageReadBase64`

## Description
 Creates a ColdFusion image from a Base64 string.

## Return Type
`any`

## Syntax
```cfml
imageReadBase64(string)
```

## Arguments

### Argument: `string`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: a variable or Base64 string
