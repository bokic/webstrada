# Function Name: `RestSetResponse`

## Description
 Sets the custom responses.

## Return Type
`void`

## Syntax
```cfml
restSetResponse(response);
```

## Arguments

### Argument: `response`
- **Type**: `struct`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A struct that contains the response details.
