# Function Name: `CacheGetMetadata`

## Description
Gets the metadata values for a cached object.

## Return Type
`struct`

## Syntax
```cfml
cacheGetMetadata(id [, objectType] [, region])
```

## Arguments

### Argument: `id`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The ID of the cached object.

### Argument: `objectType`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Gets metadata for template caches.

### Argument: `region`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: The name of the cache region
