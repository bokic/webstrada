# Function Name: `ArrayPrepend`

## Description
Inserts an array element at the beginning of an array
 and shifts the positions of the existing elements to
 make room.

## Return Type
`boolean`

## Syntax
```cfml
arrayPrepend(array, value)
```

## Arguments

### Argument: `array`
- **Type**: `array`
- **Required**: Required
- **Default Value**: *None*

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
