# Function Name: `SpreadsheetAddSplitPane`

## Description
 Adds split pane to spreadsheet.

## Return Type
`void`

## Syntax
```cfml
spreadsheetAddSplitPane(spreadsheetObj, x, y, splitColumn, splitRow [, position])
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Spreadsheet variable

### Argument: `x`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: X position for split

### Argument: `y`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Y position for split

### Argument: `splitColumn`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Split Column

### Argument: `splitRow`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Split Row

### Argument: `position`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specify which pane has the focus
