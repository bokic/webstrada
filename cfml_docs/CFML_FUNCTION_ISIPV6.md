# Function Name: `IsIPv6`

## Description
Checks if given IP is of IPV6 format

## Return Type
`boolean`

## Syntax
```cfml
isIPV6(value)
```

## Arguments

### Argument: `value`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: IP address to check
