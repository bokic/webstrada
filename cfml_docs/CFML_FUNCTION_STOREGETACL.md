# Function Name: `StoreGetACL`

## Description
 Gets the ACL object or bucket.

## Return Type
`any`

## Syntax
```cfml
storeGetACL(url, ACLObject);
```

## Arguments

### Argument: `ulr`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Amazon S3 URLs (content or object)

### Argument: `ACLObject`
- **Type**: `array`
- **Required**: Required
- **Default Value**: *None*
- **Description**: An array of struct where each struct represents a permission or grant as discussed in ACLObject.
