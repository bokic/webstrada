# Function Name: `IsImageFile`

## Description
Verifies whether an image file is valid.

## Return Type
`boolean`

## Syntax
```cfml
isImageFile(value)
```

## Arguments

### Argument: `value`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Pathname to an image file.
