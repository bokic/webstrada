# Function Name: `ArrayClear`

## Description
 Removes all elements from an array.

## Return Type
`boolean`

## Syntax
```cfml
arrayClear(array)
```

## Arguments

### Argument: `array`
- **Type**: `array`
- **Required**: Required
- **Default Value**: *None*
- **Description**: An array name or variable name

## Limitations and Other Info

- **Type Requirement**: The first argument must be a valid array. Standard array functions in CFML are 1-indexed.
- **Related Functions**: `ArrayDelete`, `ArrayDeleteAt`
