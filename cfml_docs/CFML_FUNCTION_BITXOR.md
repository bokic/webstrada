# Function Name: `BitXor`

## Description
Performs a bitwise logical XOR operation.

## Return Type
`numeric`

## Syntax
```cfml
bitXor(number1, number2)
```

### Argument: `number1`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Integer

### Argument: `number2`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Integer
