# Function Name: `IsSpreadsheetObject`

## Description
Checks if given object is spreadsheet object or not

## Return Type
`boolean`

## Syntax
```cfml
isSpreadsheetObject(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Any Object
