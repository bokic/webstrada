# Function Name: `DecodeForHTML`

## Description
 Decodes an HTML encoded string.

## Return Type
`string`

## Syntax
```cfml
decodeForHTML(string);
```

## Arguments

### Argument: `string`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The encoded string to decode.
