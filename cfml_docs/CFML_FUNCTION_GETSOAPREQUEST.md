# Function Name: `GetSOAPRequest`

## Description
Returns an XML object that contains the entire SOAP request. Usually called from within a web service CFC.

## Return Type
`any`

## Syntax
```cfml
getSOAPRequest(webservice)
```

## Arguments

### Argument: `webservice`
- **Type**: `any`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: A webservice object as returned from the cfobject tag or the createObject function
