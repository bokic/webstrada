# Function Name: `ArrayIsDefined`

## Description
Determines whether an array element is defined in a given index.

## Return Type
`boolean`

## Syntax
```cfml
arrayIsDefined(array, index)
```

## Arguments

### Argument: `array`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The array object

### Argument: `index`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The index to check.

## Limitations and Other Info

- **Type Requirement**: The first argument must be a valid array. Standard array functions in CFML are 1-indexed.
- **Related Functions**: `ArrayIsEmpty`
