# Function Name: `CreateTime`

## Description
 Creates a time variable.

## Return Type
`date`

## Syntax
```cfml
createTime(hour, minute, second)
```

## Arguments

### Argument: `hour`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Hour of the day in 24-hour notation (0-23)

### Argument: `minute`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: `0`
- **Description**: Minute within the hour

### Argument: `second`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: `0`
- **Description**: Second within the minute

- **Required**: Optional
