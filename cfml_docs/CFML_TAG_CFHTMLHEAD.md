# Tag Name: `cfhtmlhead`

## Description
Writes text to the head section of a generated HTML page. It is
 useful for embedding JavaScript code, or putting other HTML
 tags, such as meta, link, title, or base in an HTML page
 header.

## Syntax
```cfml
<cfhtmlhead text="">
```

## Attributes / Variants

### Attribute: `text`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Text to add to the head area of an HTML page. In Lucee a closing tag can be used and then the body between the tags is added to the head

## Limitations

- **Must be nested inside**: *None*
- **Must not be nested inside**: *None*
