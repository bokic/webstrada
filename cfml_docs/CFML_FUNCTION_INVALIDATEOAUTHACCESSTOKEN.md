# Function Name: `InvalidateOauthAccesstoken`

## Description
Invalidates the access token generated by the OAUTH servers.

## Return Type
`void`

## Syntax
```cfml
invalidateOauthAccesstoken(token,type);
```

## Arguments

### Argument: `token`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The access token to invalidate.

### Argument: `type`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The type of the OAUTH server (facebook/google).

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `11`.
