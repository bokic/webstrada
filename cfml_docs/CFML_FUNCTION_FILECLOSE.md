# Function Name: `FileClose`

## Description
Closes an on-disk or in-memory file that is open.

## Return Type
`void`

## Syntax
```cfml
fileClose(file)
```

## Arguments

### Argument: `file`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A file object

## Limitations and Other Info

- **Permission/IO**: Requires appropriate file system read/write permissions on the target directory/path.
- **Related Functions**: `fileOpen`
