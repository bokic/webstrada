# Function Name: `IsObject`

## Description
Determines whether a value is an object.
True, if the value represents a CFML object. False if the value is any other type of data, such as an integer, string, date, or struct.

## Return Type
`boolean`

## Syntax
```cfml
isObject(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
