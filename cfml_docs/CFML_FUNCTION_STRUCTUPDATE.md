# Function Name: `StructUpdate`

## Description
 Updates a key with a value.

## Return Type
`boolean`

## Syntax
```cfml
structUpdate(structure, key, value)
```

## Arguments

### Argument: `structure`
- **Type**: `struct`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Structure to update

### Argument: `key`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Key, the value of which to update

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: New value

## Limitations and Other Info

- **Type Requirement**: The first argument must be a valid structure/associative array.
