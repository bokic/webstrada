# Function Name: `FindNoCase`

## Description
Finds the first occurrence of a substring in a string, from a specified start position. If substring is not in string, returns zero. The search is case-insensitive.

## Return Type
`numeric`

## Syntax
```cfml
findNoCase(substring, string [, start])
```

## Arguments

### Argument: `substring`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The string for which you are looking

### Argument: `string`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The string in which to search

### Argument: `start`
- **Type**: `numeric`
- **Required**: Optional
- **Default Value**: `1`
- **Description**: The position from which to start searching in the string
