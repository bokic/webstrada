# Function Name: `StructGetMetadata`

## Description
Gets metadata for keys in a struct and indicates if it is an ordered struct.

## Return Type
`struct`

## Syntax
```cfml
structGetMetadata(struct)
```

## Arguments

### Argument: `struct`
- **Type**: `struct`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The struct in which you want to add the metadata.

## Limitations and Other Info

- **Type Requirement**: The first argument must be a valid structure/associative array.
- **Related Functions**: `arraySetMetadata`, `arrayGetMetadata`, `structSetMetadata`
- **Coldfusion Support**: Minimum version: `2016.0.2`.
- **Boxlang Support**: Minimum version: `1.0.0`.
