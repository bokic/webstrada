# Function Name: `ImageGetMetadata`

## Description
A structure containing information about the image.

## Return Type
`struct`

## Syntax
```cfml
imageGetMetadata(image)
```

## Arguments

### Argument: `name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The image on which this operation is performed.

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `11`.
