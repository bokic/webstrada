# Function Name: `IsXmlElem`

## Description
Determines whether a function parameter is an Extended Markup
 language (XML) document object element.

## Return Type
`boolean`

## Syntax
```cfml
isXMLElem(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: XML Element
