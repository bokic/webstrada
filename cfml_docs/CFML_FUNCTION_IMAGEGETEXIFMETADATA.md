# Function Name: `ImageGetEXIFMetadata`

## Description
Retrieves the Exchangeable Image File Format (EXIF) headers in an image as a CFML structure.

## Return Type
`struct`

## Syntax
```cfml
imageGetEXIFMetadata(name)
```

## Arguments

### Argument: `name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The image on which this operation is performed.
