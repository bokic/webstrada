# Function Name: `IsXmlNode`

## Description
Determines whether the function parameter is an XML document object node.

## Return Type
`boolean`

## Syntax
```cfml
isXMLNode(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: XML document object node.
