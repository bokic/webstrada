# Tag Name: `cfproperty`

## Description
Defines properties of a CFML component (CFC). Used to
 create complex data types for web services. The attributes of
 this tag are exposed as component metadata and are subject to
 inheritance rules.

## Syntax
```cfml
<cfproperty name="">
```

## Attributes / Variants

### Attribute: `name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Specifies the name of the property.

### Attribute: `type`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies the ColdFusion data type for the property.

### Attribute: `required`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Whether the parameter is required

### Attribute: `default`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: This sets the default value on the property when the object is created. For ORM Entities, this only works for static values. Variable values like the current timestamp can be set by a function "preInsert" in the component.

### Attribute: `displayname`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: A value to be displayed when using introspection to show
 information about the CFC. The value appears in parentheses
 following the property name.

### Attribute: `hint`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Text to be displayed when using introspection to show
 information about the CFC. This attribute can be useful
 for describing the purpose of the parameter.

### Attribute: `fieldtype`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: This attribute is used to specify the type of the property. Use this attribute to specify the following:
* Primary key: Specify fieldtype = "id" to map a property to the primary key in the table. 
* Column: Specify the fieldtype = "column" to map a property to a column in the table.
* Relationship: Specify the fieldtype = "relationship_type". The relationship_type can be one-to-one, one-to-many, many-to-one, or many-to-many.
* Version: Specify the fieldtype="version‚Äù to indicate that the column contains versioned data.
* Timestamp: Specify the fieldtype="timestamp" to indicate the column contains data with timestamp.
* Collection: Specify the fieldtype="collection" to define the collection mapping.

### Attribute: `ormType`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Used to specify the data type of the primary key. If data type is not set and the ORM setting
useDBForMapping=true, then the ormtype is determined by inspecting the database.

### Attribute: `column`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Used to specify the primary key column name.

### Attribute: `generator`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Algorithm used to generate unique identifiers for instances of the persistent CFC.

### Attribute: `sequence`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Sequence key name in the database.

### Attribute: `selectkey`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: The column name that is used to retrieve the primary key generated by a database trigger.

### Attribute: `params`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Additional parameters required by the various generators to generate the ID.
The value for the params attribute should follow the CF Struct syntax. For example: params = {key1='value1', key2='value2'}

### Attribute: `length`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Use this attribute to specify the length of the column. This attribute is used for table creation only.

### Attribute: `precision`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies the precision value.

### Attribute: `index`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies the name of an index that is created using the mapped column

### Attribute: `setter`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies whether to generate setter methods or not

### Attribute: `getter`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies whether to generate getter methods or not

### Attribute: `source`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: `vm`
- **Description**: Specifies the source from where the timestamp has to be retrieved

### Attribute: `elementcolumn`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Column name in the table that is used as value in struct.

### Attribute: `elementtype`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Data type of the value.

### Attribute: `structkeytype`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies the data type of the key, when collectiontype=struct.

### Attribute: `structkeycolumn`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: The column in the target table to use as key if the collection type is struct.

### Attribute: `inversejoincolumn`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies the foreign key column in the Join table that references the primary key column in the target table.

### Attribute: `linkschema`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Schema for the link table

### Attribute: `linkcatalog`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Catalog for the link table

### Attribute: `linktable`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Name of the link table

### Attribute: `missingRowIgnored`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: If the value is true, and the row that is referenced by the foreign key is missing, it is treated as a null
association. The default is false, in which case an exception occurs.

### Attribute: `inverse`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: A Boolean value that specifies bidirectional association

### Attribute: `orderby`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies the Order By string.

### Attribute: `fkcolumn`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies the foreign key column

### Attribute: `fetch`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies if it is outer-join fetching or sequential select fetching

### Attribute: `cascade`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies which operations should be cascaded from the parent object to the associated object

### Attribute: `constrained`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Whether a constraint is set on this table's Primary Key column to reference the Primary Key in the other table

### Attribute: `unique`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies if there should be a unique constraint on the column.

### Attribute: `uniquekey`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Groups columns in a single unique key constraint.

### Attribute: `notnull`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: A Boolean value that specifies whether a notnull constraint should be added for this column.

### Attribute: `update`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Whether the column should be included in the SQL update statement.
Set update=false and insert=false if the column needs to be read-only.

### Attribute: `insert`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Whether the column should be included in SQL UPDATE and/or INSERT statements.
Set update=false and insert=false if the column needs to be read-only.

### Attribute: `generated`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies that this property value is actually generated by the database {never|always|insert}
* never: Specifies that the value for this property is never generated by database
* always: Specifies that the value for this property is always generated by database
* insert: Specifies that the value for this property is generated at the time of insert but is not regenerated at updates.

### Attribute: `formula`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: SQL expression that defines the value of the property. If you specify a formula, the column value is ignored.

### Attribute: `lazy`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies if loading is to be done by parts:

### Attribute: `optimisticLock`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Whether updates to this property require acquisition of the optimistic lock on the table row

### Attribute: `scale`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies the scale value

### Attribute: `mappedby`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Property in the target CFC that is referenced by the foreign key in the Join table.

### Attribute: `cfc`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Name of referenced CFC

### Attribute: `joinColumn`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Use this attribute to define the join column for inheritance mapping.

### Attribute: `validate`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Takes the validator to be used for validating data when implicit setter for this property is called.

### Attribute: `validateParams`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Takes the parameters required by the validator specified in the validate attribute. 
 This should be specified in the implicit struct notation eg. validateparams="{min=18,max=60}">.

min: Minimum value if validate is integer/numeric/
max: Maximum value if the validate is integer/numeric/
minLength: Minimum length of the string if the validate is string
maxLength: Maximum length of the string if the validate is string
pattern: regex expression if the validator specified in validate attribute is regex

### Attribute: `cacheUse`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Type of cache to use

### Attribute: `sqlType`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Use this attribute to specify the DB-specific SQLType that should be used for the column. This attribute is used for table creation only.
If this attribute is not specified, ColdFusion will automatically decide the SQLType based on the ormtype specified for this property.

### Attribute: `dbDefault`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: This sets the default value of a column in the table when schema is exported.

### Attribute: `where`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Where condition

### Attribute: `persistent`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies whether this property should be persisted. If
persistent="false‚ all the ORM related attributes are ignored.
Set this attribute to false if you do not want this property to be persisted by ORM.

### Attribute: `unSavedValue`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: An identifier property value that indicates that an instance is newly instantiated and not saved/loaded in the database

### Attribute: `serializable`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies whether this property can be serialized. If you set this value to
false, the property cannot be serialized, so any changes made are not retained on session replication, and the property has its default value (if any) on the second server. 
Use this attribute to prevent serialization of properties in CFCs that are serializable.

### Attribute: `singularname`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Use this property to define the custom name for generated relationship methods. Applies to one-to-many and many-to-many

### Attribute: `remotingFetch`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: If remotingFetch is false, then the value of that attribute is not sent over flash remoting. remotingFetch is true by default was all properties. But in case of cfcs for which persistent = true, the value of the remotingFetch attribute is false by default for any property that shares one-to-one, one-to-many, many-to-one or many-to-many relationship.

### Attribute: `table`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Table name

## Limitations

- **Must be nested inside**: `cfcomponent`
- **Must not be nested inside**: *None*
