# Function Name: `Ceiling`

## Description
Determines the closest integer that is greater than a specified floating point number.

## Return Type
`numeric`

## Syntax
```cfml
ceiling(number)
```

## Arguments

### Argument: `number`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The number for which to get the ceiling
