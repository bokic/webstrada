# Function Name: `CharsetEncode`

## Description
Uses the specified encoding to convert binary data to a string.

## Return Type
`string`

## Syntax
```cfml
charsetEncode(binaryData, encoding)
```

## Arguments

### Argument: `binaryData`
- **Type**: `binary`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A variable containing binary data to decode into text.

### Argument: `encoding`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The character encoding that was used to encode the string into binary format.
