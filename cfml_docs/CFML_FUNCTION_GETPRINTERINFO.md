# Function Name: `GetPrinterInfo`

## Description
Determines which print attributes are supported by a selected printer.

## Return Type
`struct`

## Syntax
```cfml
getPrinterInfo([printer])
```

## Arguments

### Argument: `printer`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Name of the printer

## Limitations and Other Info

- **Related Functions**: `getPrinterList`, `cfprint`
- **Coldfusion Support**: Minimum version: `8`.
