# Function Name: `Cos`

## Description
Calculates the cosine of an angle that is entered in radians.

## Return Type
`numeric`

## Syntax
```cfml
cos(number)
```

## Arguments

### Argument: `number`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The angle, in radians, for which to calculate the cosine
