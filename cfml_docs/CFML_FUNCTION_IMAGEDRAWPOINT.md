# Function Name: `ImageDrawPoint`

## Description
 Draws a point at the specified (x,y) coordinate.

## Return Type
`void`

## Syntax
```cfml
imageDrawPoint(name, x, y)
```

## Arguments

### Argument: `name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The image on which this operation is performed.

### Argument: `x`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The x coordinate of the point.

### Argument: `y`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The y coordinate of the point.
