# Function Name: `Pi`

## Description
Gets the mathematical constant p, accurate to 15 digits
, but only shows 11 when simply outputted.

## Return Type
`numeric`

## Syntax
```cfml
pi()
```

## Arguments

This function does not take any arguments.
