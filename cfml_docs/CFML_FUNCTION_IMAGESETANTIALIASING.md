# Function Name: `ImageSetAntialiasing`

## Description
Switches antialiasing on or off in rendered graphics.

## Return Type
`void`

## Syntax
```cfml
imageSetAntialiasing(image [, antialias])
```

## Arguments

### Argument: `image`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The ColdFusion image on which this operation is performed.

### Argument: `antialias`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: `on`
- **Description**: Antialiasing switch
