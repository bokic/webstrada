# Function Name: `IsNumeric`

## Description
Determines whether a string can be converted to a numeric value. Supports numbers in U.S. number format. For other number support use LSIsNumeric.

## Return Type
`boolean`

## Syntax
```cfml
isNumeric(String)
```
