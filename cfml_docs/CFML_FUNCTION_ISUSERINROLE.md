# Function Name: `IsUserInRole`

## Description
Determines whether an authenticated user belongs to the specified Role.

## Return Type
`string`

## Syntax
```cfml
isUserInRole(value)
```

## Arguments

### Argument: `value`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Name of a security role
