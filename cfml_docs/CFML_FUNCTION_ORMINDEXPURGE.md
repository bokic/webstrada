# Function Name: `ORMIndexPurge`

## Description
Clears all indexed data for all entities or specified entities in the current application scope.

## Return Type
`void`

## Syntax
```cfml
ormIndexPurge(); ormIndexPurge("entityName"); ormIndexPurge("entityName_list");
```

## Arguments

### Argument: `region`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Name of the cache region.

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `10`.
