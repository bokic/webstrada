# Function Name: `FileIsEOF`

## Description
Determines whether ColdFusion has reached the end of the file while reading it.

## Return Type
`boolean`

## Syntax
```cfml
fileIsEOF(file)
```

## Arguments

### Argument: `file`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The file object.

## Limitations and Other Info

- **Permission/IO**: Requires appropriate file system read/write permissions on the target directory/path.
- **Coldfusion Support**: Minimum version: `8`.
