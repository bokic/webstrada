# Function Name: `StoreAddACL`

## Description
Adds ACL to existing ACL for object or bucket.

## Return Type
`void`

## Syntax
```cfml
storeAddACL(url, ACLObject);
```

## Arguments

### Argument: `url`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Amazon S3 URLs (content or object).

### Argument: `ACLObject`
- **Type**: `array`
- **Required**: Required
- **Default Value**: *None*
- **Description**: An array of struct where each struct represents a permission or grant as discussed in ACLObject.
