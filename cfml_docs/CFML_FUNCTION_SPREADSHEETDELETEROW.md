# Function Name: `SpreadsheetDeleteRow`

## Description
 Deletes all data from a row of an Excel spreadsheet object. It does not delete the row.

## Return Type
`void`

## Syntax
```cfml
spreadsheetDeleteRow(spreadsheetObj, row)
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: No Help Available

### Argument: `row`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: No Help Available
