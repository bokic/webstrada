# Function Name: `ORMGetSessionFactory`

## Description
Returns ORM session factory instance

## Return Type
`any`

## Syntax
```cfml
ormGetSessionFactory([datasource])
```

## Arguments

### Argument: `datasource`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Name of the data source used for the session. If not defined, the default datasource defined in Application.cfc/cfapplication is used.
