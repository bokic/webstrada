# Function Name: `Sleep`

## Description
Causes the current thread to stop processing for a specified period of time.

## Return Type
`void`

## Syntax
```cfml
sleep(duration)
```

## Arguments

### Argument: `duration`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Time, in milliseconds, to stop processing the current thread
