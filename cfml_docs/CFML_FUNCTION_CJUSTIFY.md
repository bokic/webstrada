# Function Name: `CJustify`

## Description
Centers a string in a given field length by adding spaces to either side.

## Return Type
`string`

## Syntax
```cfml
cJustify(string, length)
```

## Arguments

### Argument: `string`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The string that is to be centered

### Argument: `length`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The length of the field in which the string should be centered
