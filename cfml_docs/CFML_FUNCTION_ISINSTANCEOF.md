# Function Name: `IsInstanceOf`

## Description
Determines whether an object is an instance of a ColdFusion interface or component, or of a Java class.

## Return Type
`boolean`

## Syntax
```cfml
isInstanceOf(value, type)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The CFC instance or Java object that you are testing

### Argument: `type`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The name of the interface, component, or Java class of which the object might be an instance
