# Function Name: `IsUserInAnyRole`

## Description
Determines whether an authenticated user belongs to any role in a list of roles.

## Return Type
`boolean`

## Syntax
```cfml
isUserInAnyRole(value)
```

## Arguments

### Argument: `value`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A comma-delimited list of one or more roles to be tested
