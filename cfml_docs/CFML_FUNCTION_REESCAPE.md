# Function Name: `ReEscape`

## Description
Escapes regular expression control characters within a string.

## Return Type
`string`

## Syntax
```cfml
reEscape(string);
```

## Arguments

### Argument: `string`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The string you that to escape.
