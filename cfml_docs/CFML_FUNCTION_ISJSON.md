# Function Name: `IsJSON`

## Description
Evaluates whether a string is in valid JSON (JavaScript Object Notation) data interchange format.

## Return Type
`boolean`

## Syntax
```cfml
isJSON(value)
```

## Arguments

### Argument: `value`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string or variable that represents one.
