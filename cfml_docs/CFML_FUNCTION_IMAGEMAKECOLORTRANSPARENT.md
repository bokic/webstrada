# Function Name: `ImageMakeColorTransparent`

## Description
 Creates an image and sets a transparent color.

## Return Type
`any`

## Syntax
```cfml
imageMakeColorTransparent(img, color__);
```

## Arguments

### Argument: `img`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The ColdFusion image on which this operation is performed.

### Argument: `color`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The transparent color: Hexadecimal, String value, Default is black.

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `10`.
