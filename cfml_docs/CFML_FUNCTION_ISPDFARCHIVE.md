# Function Name: `IsPDFArchive`

## Description
Returns `true` if the pdf file at the specified `path` meets the specified `standard`.

## Return Type
`boolean`

## Syntax
```cfml
isPDFArchive(path, standard)
```

## Arguments

### Argument: `path`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Path to a PDF file.

### Argument: `standard`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: PDF Archiving Standard

## Limitations and Other Info

- **Related Functions**: `isPDFFile`
- **Coldfusion Support**: Minimum version: `2016`.
