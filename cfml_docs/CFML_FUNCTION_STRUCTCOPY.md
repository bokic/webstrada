# Function Name: `StructCopy`

## Description
 Copies a structure. Copies top-level keys, values, and arrays
 in the structure by value; copies nested structures by
 reference.

## Return Type
`struct`

## Syntax
```cfml
structCopy(structure)
```

## Arguments

### Argument: `structure`
- **Type**: `struct`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Structure to copy

## Limitations and Other Info

- **Type Requirement**: The first argument must be a valid structure/associative array.
