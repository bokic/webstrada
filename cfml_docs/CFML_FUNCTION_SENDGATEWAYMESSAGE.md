# Function Name: `SendGatewayMessage`

## Description
 Sends an outgoing message through a ColdFusion MX event gateway.

## Return Type
`string`

## Syntax
```cfml
sendGatewayMessage(gatewayID, data)
```

## Arguments

### Argument: `gatewayID`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Identifier of the gateway to send the message.

### Argument: `data`
- **Type**: `struct`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A ColdFusion structure.
