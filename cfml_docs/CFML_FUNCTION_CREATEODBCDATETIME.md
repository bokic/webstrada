# Function Name: `CreateODBCDateTime`

## Description
Creates an ODBC date-time object.

## Return Type
`date`

## Syntax
```cfml
createODBCDateTime(date)
```

## Arguments

### Argument: `date`
- **Type**: `date`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Date or date/time object or string.
