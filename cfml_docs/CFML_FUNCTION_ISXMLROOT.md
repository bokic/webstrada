# Function Name: `IsXmlRoot`

## Description
Determines whether a function parameter is the root element of an Extended Markup language (XML) document object.

## Return Type
`boolean`

## Syntax
```cfml
isXMLRoot(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: XML Element
