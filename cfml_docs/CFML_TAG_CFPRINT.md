# Tag Name: `cfprint`

## Description
Prints specified pages from a PDF file. Use this tag to perform automated batch print jobs. 
 You can use the cfprint tag to print any PDF document, including those generated by the 
 cfdocument, cfpdf, and cfpdfform tag. Also, you can use this tag to print Report Builder 
 reports exported in PDF format.

## Syntax
```cfml
<cfprint>
```

## Attributes / Variants

### Attribute: `source`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Source document to print. You can specify 
 one of the following: 
An absolute or relative pathname to a PDF 
 document; for example, 
 c:\work\myPDF.pdf or myPDF.pdf. The 
 default directory is the template directory. 
A PDF document variable in memory that 
 is generated by the cfdocument tag or the 
 cfpdf tag; for example, "myPDFdoc".

### Attribute: `attributestruct`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: ColdFusion structure used to specify 
 additional print instructions. Individually 
 named attributes take precedence over the 
 key-value pairs in the attribute structure.

### Attribute: `copies`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Number of copies to print. The value must be 
 greater than or equal to 1.

### Attribute: `jobname`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: The name of a print job.

### Attribute: `orientation`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Orientation of the page to be printed.

### Attribute: `pages`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Pages in the source file to print. Duplicate 
 pages and pages beyond the total count of 
 pages in the document are ignored as long 
 as there is at least one page between 1 and 
 the total number of pages in the document. 
 You can combine individual page numbers 
 and page ranges; for example, 1-3,6,10-20. 
 If you do not specify a value for the pages 
 attribute, ColdFusion prints the entire 
 document.

### Attribute: `password`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies either the owner or user password 
 for the PDF source file. If the PDF file is 
 password-protected, you must specify this 
 attribute for the file to print.

### Attribute: `papersize`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Paper used for the print job. The value can be 
 any returned by the GetPrinterInfo 
 function. Valid

### Attribute: `quality`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Print quality for the print job:

 * draft
 * high
 * normal

### Attribute: `color`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Color or monochrome printing

### Attribute: `coverpage`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies which job start and end sheets, if any, are printed with a job:

 * none
 * standard

### Attribute: `type`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies the file type of the document being 
 printed. PDF is the only valid value.

### Attribute: `printer`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: The name of a printer. An example in 
 Windows is \s1001prn02\NTN-2W- 
 HP_BW02. The default is the default printer 
 for the account where the ColdFusion server 
 is running.

### Attribute: `sides`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: 

### Attribute: `paper`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Paper used for the print job. The value can be any returned by the GetPrinterInfo function.

### Attribute: `fidelity`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: `False`
- **Description**: Whether to print a job based on the print requirements specified. Valid values are:
 * yes: if the job cannot be printed exactly as specified in the print requirements, the job is rejected.
 * no: a reasonable attempt to print the job is acceptable

## Limitations

- **Must be nested inside**: *None*
- **Must not be nested inside**: *None*
