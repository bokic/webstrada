# Function Name: `SpreadsheetGetColumnCount`

## Description
Returns the number of columns in a given spreadsheet.

## Return Type
`numeric`

## Syntax
```cfml
spreadsheetAddRow(spreadsheetObj, [sheet])
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The spreadsheet object

### Argument: `sheet`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: The sheet name or sheet number

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `2016`.
