# Function Name: `IsPDFObject`

## Description
Determines whether a value is a PDF object.

## Return Type
`boolean`

## Syntax
```cfml
isPDFObject(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A value, typically the PDF object stored as a variable.
