# Function Name: `GetMetaData`

## Description
Gets metadata (the methods, properties, and parameters of a component) associated with an object that is deployed on the CFML server.

## Return Type
`any`

## Syntax
```cfml
getMetadata(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A ColdFusion component, user-defined function, or ColdFusion query. Within a CFC, the parameter can also specify the `this` scope.
