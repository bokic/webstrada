# Function Name: `StructKeyArray`

## Description
Returns the keys in a CFML structure as an array. If structure does not exist throws an exception.

## Return Type
`array`

## Syntax
```cfml
structKeyArray(structure)
```

## Arguments

### Argument: `structure`
- **Type**: `struct`
- **Required**: Required
- **Default Value**: *None*
