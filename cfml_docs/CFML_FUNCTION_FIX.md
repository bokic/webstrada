# Function Name: `Fix`

## Description
Converts a real number to an integer.
**Tip:** If you want to `fix()` the outcome of a division, simply use the integer division operator (\).

## Return Type
`numeric`

## Syntax
```cfml
fix(number)
```

## Arguments

### Argument: `number`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The number to convert
