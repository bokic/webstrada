# Function Name: `ToBase64`

## Description
 Calculates the Base64 representation of a string or binary
 object. The Base64 format uses printable characters, allowing
 binary data to be sent in forms and e-mail, and stored in a
 database or file.

## Return Type
`string`

## Syntax
```cfml
toBase64(string_or_object [, encoding])
```

## Arguments

### Argument: `string_or_object`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string, the name of a string, or a binary object.

### Argument: `encoding`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: For a string, defines how characters are represented in a
 byte array.
