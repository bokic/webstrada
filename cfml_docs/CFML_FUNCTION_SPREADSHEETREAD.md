# Function Name: `SpreadsheetRead`

## Description
Create a new spreadsheet variable from specified file

## Return Type
`void`

## Syntax
```cfml
spreadsheetRead(fileName, spreadsheetObj)
```

## Arguments

### Argument: `fileName`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Path to spreadsheet file

### Argument: `spreadsheetObj`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Spreadsheet name or number
