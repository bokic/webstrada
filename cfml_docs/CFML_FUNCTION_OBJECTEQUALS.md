# Function Name: `ObjectEquals`

## Description
Identifies any conflict between CFC instances on the client and the server.

## Return Type
`boolean`

## Syntax
```cfml
objectEquals(clientobject, originalobject)
```

## Arguments

### Argument: `clientobject`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: New instance of the CFC on the client.

### Argument: `originalobject`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Original instance of the CFC.
