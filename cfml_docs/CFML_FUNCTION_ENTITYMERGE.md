# Function Name: `EntityMerge`

## Description
Attaches given entity to current ORM session

## Return Type
`any`

## Syntax
```cfml
entityMerge(entity)
```

## Arguments

### Argument: `entity`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The entity that must be attached to the ORM session.
