# Function Name: `ImageInfo`

## Description
 Returns a structure that contains information about the image, such as height, width, color model, size, and filename.

## Return Type
`struct`

## Syntax
```cfml
imageInfo(name)
```

## Arguments

### Argument: `name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The image on which this operation is performed.
