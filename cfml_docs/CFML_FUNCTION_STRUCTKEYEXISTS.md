# Function Name: `StructKeyExists`

## Description
Determines whether a specific key is present in a structure.

## Return Type
`boolean`

## Syntax
```cfml
structKeyExists(structure, key)
```

## Arguments

### Argument: `structure`
- **Type**: `struct`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Name of structure to test

### Argument: `key`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Key to test

## Limitations and Other Info

- **Type Requirement**: The first argument must be a valid structure/associative array.
