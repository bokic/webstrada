# Function Name: `AjaxOnLoad`

## Description
Causes the specified JavaScript function to run when the page loads.

## Return Type
`void`

## Syntax
```cfml
ajaxOnLoad(functionName)
```

## Arguments

### Argument: `functionName`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The name of the function to run when the page loads.
