# Function Name: `URLDecode`

## Description
Decodes a URL-encoded string.

## Return Type
`string`

## Syntax
```cfml
urlDecode(urlencodedstring [, charset])
```

## Arguments

### Argument: `urlencodedstring`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: 

### Argument: `charset`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: The character encoding in which the string is encoded.
