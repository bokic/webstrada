# Function Name: `IncrementValue`

## Description
Increment the integer part of a number.
Same as x=x+1 or x++

## Return Type
`numeric`

## Syntax
```cfml
incrementValue(number)
```

## Arguments

### Argument: `number`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: 

## Limitations and Other Info

- **Related Functions**: `decrementValue`
- **Coldfusion Support**: Notes: For floats ACF will return the integer incremented removing the decimal part
- **Lucee Support**: Notes: For floats Lucee will keep the decimal part while incrementing
