# Function Name: `Tan`

## Description
 Calculates the tangent of an angle that is entered in radians.

## Return Type
`numeric`

## Syntax
```cfml
tan(number)
```

## Arguments

### Argument: `number`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Angle, in radians, for which to calculate the tangent
