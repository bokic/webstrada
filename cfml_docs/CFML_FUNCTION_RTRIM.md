# Function Name: `RTrim`

## Description
 Removes spaces from the end of a string.

## Return Type
`string`

## Syntax
```cfml
rTrim(String)
```

## Arguments

### Argument: `String`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string or a variable that contains one
