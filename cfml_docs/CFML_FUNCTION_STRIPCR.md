# Function Name: `StripCR`

## Description
 Deletes return characters from a string.

## Return Type
`string`

## Syntax
```cfml
stripCR(String)
```

## Arguments

### Argument: `String`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string or a variable that contains one
