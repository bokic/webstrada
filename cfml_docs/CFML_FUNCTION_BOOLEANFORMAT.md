# Function Name: `BooleanFormat`

## Description
Evaluates the input as a boolean, and outputs either true or false. If not a boolean throws an exception.

## Return Type
`string`

## Syntax
```cfml
booleanFormat(value)
```

## Arguments

### Argument: `value`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: 

## Limitations and Other Info

- **Related Functions**: `yesNoFormat`, `isBoolean`, `trueFalseFormat`
- **Coldfusion Support**: Minimum version: `2016`.
- **Lucee Support**: Minimum version: `5.1.0`. Notes: Due to Lucee's strict typing, the return value is NOT considered as a boolean
- **Boxlang Support**: Minimum version: `1.0.0`.
