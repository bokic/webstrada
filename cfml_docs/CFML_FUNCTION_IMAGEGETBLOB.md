# Function Name: `ImageGetBlob`

## Description
Retrieves the bytes of the underlying image. The bytes are in the same image format as the source image.

## Return Type
`binary`

## Syntax
```cfml
imageGetBlob(source)
```

## Arguments

### Argument: `source`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The ColdFusion image on which this operation is performed.
