# Function Name: `XmlGetNodeType`

## Description
Determines the type of an XML document object node.

## Return Type
`string`

## Syntax
```cfml
xmlGetNodeType(xmlNode)
```

## Arguments

### Argument: `xmlNode`
- **Type**: `xml`
- **Required**: Required
- **Default Value**: *None*
- **Description**: An XML DOM object node.

## Limitations and Other Info

- **Type Requirement**: Operates on XML document objects or XML markup strings.
