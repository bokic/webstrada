# Function Name: `Compare`

## Description
Performs a case-sensitive comparison of two strings.
 -1, if string1 is less than string2
 0, if string1 is equal to string2
 1, if string1 is greater than string2

## Return Type
`numeric`

## Syntax
```cfml
compare(string1, string2)
```
