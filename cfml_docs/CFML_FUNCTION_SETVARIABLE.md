# Function Name: `SetVariable`

## Description
Sets a variable in the name parameter to the value of the value parameter.

## Return Type
`void`

## Syntax
```cfml
setVariable(name, value)
```

## Arguments

### Argument: `name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Variable name

### Argument: `value`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string, the name of a string, or a number
