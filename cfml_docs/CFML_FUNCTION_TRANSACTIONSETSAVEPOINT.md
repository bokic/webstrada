# Function Name: `TransactionSetSavePoint`

## Description
Set savepoint for transaction

## Return Type
`void`

## Syntax
```cfml
transactionSetSavepoint(savepoint)
```

## Arguments

### Argument: `savepoint`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Savepoint name to which can be rolled back
