# Function Name: `FileWriteLine`

## Description
Appends content to an existing file

## Return Type
`void`

## Syntax
```cfml
fileWriteLine(file, data)
```

## Arguments

### Argument: `file`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The file where you want to add your content

### Argument: `data`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Content to add to the file

## Limitations and Other Info

- **Permission/IO**: Requires appropriate file system read/write permissions on the target directory/path.
- **Related Functions**: `fileWrite`, `fileAppend`
