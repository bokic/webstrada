# Function Name: `ImageDrawLine`

## Description
Draws a single line defined by two sets of x and y coordinates on a ColdFusion image.

## Return Type
`void`

## Syntax
```cfml
imageDrawLine(name, x1, y1, x2, y2)
```

## Arguments

### Argument: `name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The image on which this operation is performed.

### Argument: `x1`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The x coordinate for the start point of the line.

### Argument: `y1`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The y coordinate for the start point of the line.

### Argument: `x2`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The x coordinate for the end point of the line.

### Argument: `y2`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The y coordinate for the end point of the line.
