# Function Name: `GetFreeSpace`

## Description
 Gets information about free hard disk space or free in-memory VFS space.

## Return Type
`numeric`

## Syntax
```cfml
getFreeSpace(path);
```

## Arguments

### Argument: `path`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The Path to the Hard Disk Drive or to the in-memory file system - ram.
