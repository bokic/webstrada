# Function Name: `Insert`

## Description
 Inserts a substring in a string after a specified character
 position. If position = 0, prefixes the substring to the
 string.

## Return Type
`string`

## Syntax
```cfml
insert(substring, String, position)
```

## Arguments

### Argument: `substring`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string to insert

### Argument: `String`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string, which to insert substring

### Argument: `position`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Substring add after this position value in given string
