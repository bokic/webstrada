# Function Name: `IsDDX`

## Description
Determines whether a DDX file exists and is valid, or if a string contains valid DDX instructions.

## Return Type
`boolean`

## Syntax
```cfml
isDDX(path)
```

## Arguments

### Argument: `path`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Pathname to the DDX file or a string of DDX instructions.

## Limitations and Other Info

- **Related Functions**: `isPDFObject`, `isPDFFile`, `cfpdf`
- **Coldfusion Support**: Minimum version: `8`.
