# Function Name: `SpreadsheetDeleteColumn`

## Description
 Deletes the data from a column of an Excel spreadsheet object. It does not delete the column.

## Return Type
`void`

## Syntax
```cfml
spreadsheetDeleteColumn(spreadsheetObj, column)
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: No Help Available

### Argument: `column`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: No Help Available
