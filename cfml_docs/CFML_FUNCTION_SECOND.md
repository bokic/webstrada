# Function Name: `Second`

## Description
 Extracts the ordinal for the second from a date/time object.

## Return Type
`numeric`

## Syntax
```cfml
second(date)
```

## Arguments

### Argument: `date`
- **Type**: `date`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A date/time object
