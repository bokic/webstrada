# Function Name: `IsLocalHost`

## Description
Determines whether the specified value is the localhost.

## Return Type
`boolean`

## Syntax
```cfml
isLocalhost(value)
```

## Arguments

### Argument: `value`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The value to check.
