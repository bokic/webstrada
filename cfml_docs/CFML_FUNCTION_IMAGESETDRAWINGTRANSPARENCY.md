# Function Name: `ImageSetDrawingTransparency`

## Description
 Specifies the degree of transparency of drawing functions.

## Return Type
`void`

## Syntax
```cfml
imageSetDrawingTransparency(name, percent)
```

## Arguments

### Argument: `name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The image on which this operation is performed.

### Argument: `percent`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Percent of transparency, a floating point number in range 0-100
