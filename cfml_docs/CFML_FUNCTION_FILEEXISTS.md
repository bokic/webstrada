# Function Name: `FileExists`

## Description
Determines whether a file exists

## Return Type
`boolean`

## Syntax
```cfml
fileExists(filePath)
```

## Arguments

### Argument: `filePath`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A absolute file system path string.

## Limitations and Other Info

- **Permission/IO**: Requires appropriate file system read/write permissions on the target directory/path.
- **Related Functions**: `fileWrite`, `fileDelete`, `directoryExists`
