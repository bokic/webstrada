# Function Name: `ParameterExists`

## Description
Determines whether a parameter exists. ColdFusion does not evaluate the argument.

## Return Type
`boolean`

## Syntax
```cfml
parameterExists(name)
```

## Arguments

### Argument: `parameter`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A syntactically valid parameter name.

## Limitations and Other Info

- **Coldfusion Support**: Notes: This function is deprecated, but is still available for backward compatibility until ColdFusion 2025. Use StructKeyExists() or IsDefined() functions instead.
