# Function Name: `PreserveSingleQuotes`

## Description
Prevents CFML from automatically escaping single quotation mark characters that are contained in a variable. CFML does not evaluate the argument.

## Return Type
`void`

## Syntax
```cfml
preserveSingleQuotes(variable)
```

## Arguments

### Argument: `variable`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Variable that contains a string in which to preserve single quotation marks.
