# Function Name: `DayOfYear`

## Description
 Determines the day of the year, in a date.

## Return Type
`numeric`

## Syntax
```cfml
dayOfYear(date)
```

## Arguments

### Argument: `date`
- **Type**: `date`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Date or datetime object (100AD-9999AD).
