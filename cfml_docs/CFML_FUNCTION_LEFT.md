# Function Name: `Left`

## Description
 Returns the leftmost count characters in a string.

## Return Type
`string`

## Syntax
```cfml
left(String, count)
```

## Arguments

### Argument: `String`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: 

### Argument: `count`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: An integer or a variable that contains one.
 Number of characters to return.
