# Function Name: `IsDateObject`

## Description
Checks if the given value is a date / time object. The difference between isDateObject and isDate is that the latter returns true for date / time objects as well as date / time strings.

## Return Type
`boolean`

## Syntax
```cfml
isDateObject(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A value to test whether it's a date object

## Limitations and Other Info

- **Related Functions**: `isDate`, `isObject`
- **Coldfusion Support**: Minimum version: `2016.0.3`.
- **Boxlang Support**: Minimum version: `1.0.0`.
