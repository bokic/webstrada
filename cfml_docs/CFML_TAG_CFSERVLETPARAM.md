# Tag Name: `cfservletparam`

## Description
Deprecated, invokes a servlet. Use `getPageContext().include(servletPath)` or `getPageContext().forward(servletPath)` instead.

## Syntax
```cfml
<cfservletparam>
```

## Attributes / Variants

This tag does not have any attributes or parameters.

## Limitations

- **Must be nested inside**: `cfservlet`
- **Must not be nested inside**: *None*
