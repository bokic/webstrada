# Tag Name: `cfobjectcache`

## Description
Flushes the query cache.

## Syntax
```cfml
<cfobjectcache action="clear">
```

## Attributes / Variants

### Attribute: `action`
- **Type**: `string`
- **Required**: Required
- **Default Value**: `clear`
- **Description**: clear: Clears queries from the cache in the Application
 scope

## Limitations

- **Must be nested inside**: *None*
- **Must not be nested inside**: *None*
