# Function Name: `SessionInvalidate`

## Description
Clears session scope and makes the current session identifiers no longer valid. This function does not invalidate J2EE sessions, only CF sessions (CFID/CFToken)

## Return Type
`void`

## Syntax
```cfml
sessionInvalidate()
```

## Arguments

This function does not take any arguments.

## Limitations and Other Info

- **Related Functions**: `sessionrotate`
- **Coldfusion Support**: Minimum version: `10`.
- **Lucee Support**:
- **Railo Support**: Minimum version: `4`.
- **Boxlang Support**: Minimum version: `1.0.0`.
