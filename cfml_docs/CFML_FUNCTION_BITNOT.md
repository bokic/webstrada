# Function Name: `BitNot`

## Description
Performs a bitwise logical NOT operation.

## Return Type
`numeric`

## Syntax
```cfml
bitNot(number)
```

## Arguments

### Argument: `number`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Integer
