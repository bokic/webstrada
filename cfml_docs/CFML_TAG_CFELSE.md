# Tag Name: `cfelse`

## Description
Used as the last control block in a cfif tag block to handle
 any case not identified by the cfif tag or a cfelseif tag.

## Syntax
```cfml
<cfelse>
```

## Attributes / Variants

This tag does not have any attributes or parameters.

## Limitations

- **Must be nested inside**: `cfif`
- **Must not be nested inside**: *None*
