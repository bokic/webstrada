# Function Name: `SpreadsheetSetHeader`

## Description
 Adds a header to the specified worksheet.

## Return Type
`void`

## Syntax
```cfml
spreadsheetSetHeader(spreadsheetObj, leftHeader, centerHeader, rightHeader)
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The Excel spreadsheet object to which to add the header.

### Argument: `leftHeader`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Adds the header in the left side of the worksheet.

### Argument: `centerHeader`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Adds the header in the center of the worksheet.

### Argument: `rightHeader`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Adds the header in the right side of the worksheet.
