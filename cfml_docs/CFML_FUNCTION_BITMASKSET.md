# Function Name: `BitMaskSet`

## Description
Performs a bitwise mask set operation.

## Return Type
`numeric`

## Syntax
```cfml
bitMaskSet(number, mask, start, length)
```

## Arguments

### Argument: `number`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Integer

### Argument: `mask`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Integer mask

### Argument: `start`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Start bit for the set mask (Integer in the range 0-31, inclusive)

### Argument: `length`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Length of bits in the set mask (Integer in the range 0-31, inclusive)
