# Function Name: `WSGetSubscribers`

## Description
Returns an array of struct with clientID and subscriberInfo as the keys.

## Return Type
`array`

## Syntax
```cfml
wsGetSubscribers(channel);
```

## Arguments

### Argument: `channel`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Channel whose list of subscribers you wish to retrieve.

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `10`.
