# Function Name: `IsPDFFile`

## Description
 Verifies whether a PDF file is valid.

## Return Type
`boolean`

## Syntax
```cfml
isPDFFile(path)
```

## Arguments

### Argument: `path`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Pathname to a PDF file.

## Limitations and Other Info

- **Related Functions**: `isPDFObject`, `isSpreadsheetFile`, `isSpreadsheetObject`
- **Coldfusion Support**: Minimum version: `8`.
