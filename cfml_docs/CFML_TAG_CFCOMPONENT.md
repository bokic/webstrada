# Tag Name: `cfcomponent`

## Description
Creates and defines a component object; encloses functionality that you build in CFML and enclose within cffunction tags. This tag contains one or more cffunction tags that define methods. Code within the body of this tag, other than cffunction tags, is executed when the component is instantiated (like a constructor). Components are saved in a file with a `.cfc` extension.

## Syntax
```cfml
<cfcomponent>
```

## Attributes / Variants

### Attribute: `extends`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Name of parent component from which to inherit methods and properties.

### Attribute: `output`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Specifies whether constructor code in the component can generate HTML output; does not affect output in the body
 of cffunction tags in the component.

### Attribute: `displayname`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: A string to be displayed when using introspection to show information about the CFC. The information appears on the
 heading, following the component name.
 If the style attribute is set to document, the displayname
 attribute is used as the name of the service element in the WSDL.

### Attribute: `hint`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Text to be displayed when using introspection to show information about the CFC. The hint attribute value
 appears below the component name heading. This attribute
 can be useful for describing the purpose of the parameter.
 If the style attribute is set to document, the hint
 attribute is used as the document element of the service
 in the WSDL.

### Attribute: `style`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: `rpc`
- **Description**: CF7+ Specifies whether a CFC used for web services uses RPC-encoded style or document-literal style:
 - rpc: RPC-encoded style, default
 - document: Document-literal style
 If you specify document, you must also specify the namespace,
 serviceportname, porttypename, and bindingname attributes.

### Attribute: `namespace`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF7+ Specifies the namespace used in the WSDL when using the CFC as a document-literal style web service.
 If you don't specify this attribute, ColdFusion MX
 derives the namespace from the CFC class name.
 This attribute applies only when style="document".

### Attribute: `serviceportname`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF7+ Specifies the name of the port element in the WSDL. This attribute applies only when style="document".

### Attribute: `porttypename`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF7+ Specifies the name of the porttype element in the WSDL. This attribute applies only when style="document".

### Attribute: `bindingname`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF7+ Specifies the name of the binding element in the WSDL. This attribute applies only when style="document".

### Attribute: `wsdlfile`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF7+ A properly formatted WSDL file to be used instead of WSDL generated by ColdFusion MX.
 This attribute applies only when style="document".

### Attribute: `implements`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF8+ Name of the ColdFusion interface or interfaces that this component implements. If the 
 component implements an interface, it must 
 define all the functions in the interface, and the 
 function definitions must conform to the 
 definitions specified in the interface. For more 
 information, see cfinterface. 
 A component can implement any number of 
 interfaces. To specify multiple interface, use a 
 comma delimited list, of the format 
 interface1,interface2.

### Attribute: `serviceaddress`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF8+ Specifies the SOAP URL of the web service.

### Attribute: `initmethod`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF9+ Method that will be called when ColdFusion instantiates the component

### Attribute: `persistent`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF9+ Specifies CFC is persistent or not

### Attribute: `entityname`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF9+ Specifies the name of the entity. Entity name is the name used by the ORM related functions to work with the persistent CFC. If entityname is not specified, then the CFC name is taken as the entityname. The entityname must be unique in the application.

### Attribute: `table`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF9+ Specifies the name of the database table to which the CFC maps.

### Attribute: `schema`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF9+ Used to specify the schema name.

### Attribute: `catalog`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF9+ Used to specify the database catalog name.

### Attribute: `dynamicinsert`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: `False`
- **Description**: CF9+ Specifies whether INSERT SQL is to be generated at runtime.
Only those columns whose values are not null are included in the SQL.

### Attribute: `dynamicupdate`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: `False`
- **Description**: CF9+ Specifies whether UPDATE SQL is to be generated at runtime.
Only those columns whose values are not null are included in the SQL.

### Attribute: `readonly`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF9+ Specify whether table is readonly or not

### Attribute: `selectbeforeupdate`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF9+ Specify whether Hibernate should never perform an SQL UPDATE unless it is certain that an object is actually modified.
In cases when a transient object is associated with a new session using update(), Hibernate performs an extra SQL SELECT to determine if an UPDATE is actually required.

### Attribute: `batchsize`
- **Type**: `numeric`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF9+ An integer value that specifies the number of records to be retrieved at a single instance.

### Attribute: `optimisticlock`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: `version`
- **Description**: CF9+ Determines the locking strategy.
It can be any one of the following four values:
none
version
dirty
all

- **Default Value**: `True`
- **Description**: CF9+ Whether loading is to be done lazily or not.

### Attribute: `rowid`

- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF9+ Row id

### Attribute: `discriminatorValue`

### Attribute: `joinColumn`

- **Type**: `string`

- **Default Value**: *None*

### Attribute: `saveMapping`

- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: CF9+ Specifies whether this component can be serialized. If you set this value to false, the component and the data in the component‚ This and Variables scopes cannot be serialized, so they are not retained on session replication, and the component is in its default state.

### Attribute: `attribute`
- **Type**: `boolean`
- **Required**: Optional
- **Default Value**: `True`
- **Description**: CF9+ If the attribute is set to false at the component level, then the implicit getters and setters for the individual properties are ignored.

### Attribute: `mappedSuperClass`

- **Description**: CF9.0.1+ When true on a non persistent CFC, CFCs that extend this component can inherit properties.
