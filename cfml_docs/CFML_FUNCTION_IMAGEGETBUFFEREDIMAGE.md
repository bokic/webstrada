# Function Name: `ImageGetBufferedImage`

## Description
 Returns the java.awt.BufferedImage object underlying the current ColdFusion image.

## Return Type
`any`

## Syntax
```cfml
imageGetBufferedImage(name)
```

## Arguments

### Argument: `name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The image on which this operation is performed.
