# Function Name: `CharsetDecode`

## Description
Converts a string to a binary representation.

## Return Type
`binary`

## Syntax
```cfml
charsetDecode(string, encoding)
```

## Arguments

### Argument: `string`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string containing data to encode in binary format.

### Argument: `encoding`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string specifying encoding of the input data.
