# Function Name: `ACos`

## Description
 Returns the angle whose cosine is the value passed as the argument.

## Return Type
`numeric`

## Syntax
```cfml
acos(number)
```

## Arguments

### Argument: `number`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The value to be converted into an angle. Must be between -1 and 1.
