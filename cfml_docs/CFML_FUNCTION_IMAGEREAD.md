# Function Name: `ImageRead`

## Description
 Reads the source pathname or URL and creates a ColdFusion image.

## Return Type
`any`

## Syntax
```cfml
imageRead(path)
```

## Arguments

### Argument: `path`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: On-disk or in-memory pathname or URL of the source image.
