# Function Name: `GetSOAPResponse`

## Description
Returns an XML object that contains the entire SOAP response after invoking a web service.

## Return Type
`any`

## Syntax
```cfml
getSOAPResponse(webservice)
```

## Arguments

### Argument: `webservice`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A webservice object as returned from the cfobject tag or the createObject function.
