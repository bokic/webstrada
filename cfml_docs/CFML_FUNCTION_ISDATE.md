# Function Name: `IsDate`

## Description
 Determines whether a string or Java object can be converted
 to a date/time value.

## Return Type
`boolean`

## Syntax
```cfml
isDate(Object)
```

## Arguments

### Argument: `Object`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string or variable name
