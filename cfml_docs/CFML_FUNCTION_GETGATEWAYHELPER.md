# Function Name: `GetGatewayHelper`

## Description
Gets a Java GatewayHelper object that provides methods and properties for use with a ColdFusion event gateway.

## Return Type
`any`

## Syntax
```cfml
getGatewayHelper(gatewayID)
```

## Arguments

### Argument: `gatewayID`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Identifier of the gateway that provides the GatewayHelper object.

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `7`.
