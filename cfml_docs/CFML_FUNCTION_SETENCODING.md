# Function Name: `SetEncoding`

## Description
 Sets the character encoding (character set) of Form and URL
 scope variable values; used when the character encoding of
 the input to a form, or the character encoding of a URL, is
 not in UTF-8 encoding.

## Return Type
`void`

## Syntax
```cfml
setEncoding(scope_name, charset)
```

## Arguments

### Argument: `scope_name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: 

### Argument: `charset`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The character encoding in which text in the scope
 variables is encoded.
