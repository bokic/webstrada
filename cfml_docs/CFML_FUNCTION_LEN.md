# Function Name: `Len`

## Description
 Determines the length of a string or binary object

## Return Type
`numeric`

## Syntax
```cfml
len(Object)
```

## Arguments

### Argument: `Object`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string or variable name
