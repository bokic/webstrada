# Function Name: `TransactionRollback`

## Description
Rollback current transaction

## Return Type
`void`

## Syntax
```cfml
transactionRollback([savepoint])
```

## Arguments

### Argument: `savepoint`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Name of the savepoint to roll back to
