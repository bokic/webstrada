# Tag Name: `cfflush`

## Description
Flushes currently available data to the client.

## Syntax
```cfml
<cfflush>
```

## Attributes / Variants

### Attribute: `interval`
- **Type**: `numeric`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Flushes output each time this number of bytes becomes
 available. HTML headers, and data that is already
 available when the tag is executed, are omitted from the
 count.

## Limitations

- **Must be nested inside**: *None*
- **Must not be nested inside**: *None*
