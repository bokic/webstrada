# Function Name: `ImageGetHeight`

## Description
Retrieves the height of the ColdFusion image in pixels.

## Return Type
`numeric`

## Syntax
```cfml
imageGetHeight(name)
```

## Arguments

### Argument: `name`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The image on which this operation is performed.
