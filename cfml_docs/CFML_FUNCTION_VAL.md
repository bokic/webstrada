# Function Name: `Val`

## Description
 Converts numeric characters that occur at the beginning of a
 string to a number. If conversion fails, returns zero.

## Return Type
`numeric`

## Syntax
```cfml
val(String)
```

## Arguments

### Argument: `String`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string or a variable that contains one
