# Function Name: `QueryGetResult`

## Description
 Returns the metadata of a query.

## Return Type
`struct`

## Syntax
```cfml
queryGetResult(query)
```

## Arguments

### Argument: `query`
- **Type**: `query`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The query whose metadata is to be returned.

## Limitations and Other Info

- **Type Requirement**: Operates on query recordsets.
- **Related Functions**: `QueryMap`, `QueryReduce`, `QueryEach`
- **Coldfusion Support**: Minimum version: `2016.3`.
- **Boxlang Support**: Minimum version: `1.0.0`.
