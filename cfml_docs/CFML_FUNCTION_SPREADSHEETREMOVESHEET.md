# Function Name: `SpreadsheetRemoveSheet`

## Description
Deletes a spreadsheet.

## Return Type
`void`

## Syntax
```cfml
spreadsheetRemoveSheet (spreadsheetObj, sheetname);
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The Excel spreadsheet object from which you delete the sheet.

### Argument: `sheetname`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Name of the sheet that must be removed.

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `9.0.1`.
