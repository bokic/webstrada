# Function Name: `GetWriteableImageFormats`

## Description
Returns a list of image formats that ColdFusion can write on the operating system where ColdFusion is deployed.

## Return Type
`string`

## Syntax
```cfml
getWriteableImageFormats()
```

## Arguments

This function does not take any arguments.

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `8`.

- **Railo Support**:
- **Boxlang Support**: Minimum version: `1.0.0`. Notes: Requires the `bx-image` module.
