# Function Name: `ORMFlushall`

## Description
Flushes all the current Hibernate sessions in the request.

## Return Type
`void`

## Syntax
```cfml
ormFlushAll();
```

## Arguments

This function does not take any arguments.

## Limitations and Other Info

- **Related Functions**: `ormFlush`
- **Coldfusion Support**: Minimum version: `9.0.1`.
