# Function Name: `ORMGetSession`

## Description
Get the current ORM session object

## Return Type
`any`

## Syntax
```cfml
ormGetSession([datasource])
```

## Arguments

### Argument: `datasource`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Name of the data source used for the session. If not defined, the default datasource defined in Application.cfc/cfapplication is used.
