# Function Name: `GetTimeZoneInfo`

## Description
 Gets local time zone information for the computer on which it
 is called, relative to Universal Time Coordinated (UTC). UTC is
 the mean solar time of the meridian of Greenwich, England.

## Return Type
`any`

## Syntax
```cfml
getTimezoneInfo(text)
```

## Arguments

### Argument: `timezone`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Lucee Specify a timezone to return info from

### Argument: `locale`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Lucee Locale used to format the output
