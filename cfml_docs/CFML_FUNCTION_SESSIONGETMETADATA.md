# Function Name: `SessionGetMetaData`

## Description
 Returns meta data related to the current session.

## Return Type
`struct`

## Syntax
```cfml
sessionGetMetadata();
```

## Arguments

### Argument: `region`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Name of the cache region.

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `10`.
