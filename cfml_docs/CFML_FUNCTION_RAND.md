# Function Name: `Rand`

## Description
 Generates a pseudo-random number in the range 0 - 1.

## Return Type
`numeric`

## Syntax
```cfml
rand([algorithm])
```

## Arguments

### Argument: `algorithm`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: `CFMX_COMPAT`
- **Description**: The algorithm to use to generated the random number.
