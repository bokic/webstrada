# Function Name: `GetPrinterList`

## Description
Returns list of printers accessible by the ColdFusion server

## Return Type
`string`

## Syntax
```cfml
getPrinterList([delimiter])
```

## Arguments

### Argument: `delimiter`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: list separator

- **Related Functions**: `getPrinterInfo`, `cfprint`
