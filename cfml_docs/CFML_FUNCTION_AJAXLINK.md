# Function Name: `AjaxLink`

## Description
Causes an HTML href attribute to display link results in the current Ajax container.

## Return Type
`void`

## Syntax
```cfml
ajaxLink(url)
```

## Arguments

### Argument: `url`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The URL of the link.
