# Function Name: `SpreadsheetDeleteRows`

## Description
 Deletes all data from multiple rows of an Excel spreadsheet object. It does not delete the row.

## Return Type
`void`

## Syntax
```cfml
spreadsheetDeleteRows(spreadsheetObj, range)
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: No Help Available

### Argument: `range`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: No Help Available
