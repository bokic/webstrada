# Function Name: `URLSessionFormat`

## Description
If the client does not accept cookies appends session identifiers `CFID`, `CFTOKEN` and / or `JSESSIONID` to the URL.

## Return Type
`string`

## Syntax
```cfml
urlSessionFormat(requesturl)
```

## Arguments

### Argument: `requesturl`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: URL of a CFML page
