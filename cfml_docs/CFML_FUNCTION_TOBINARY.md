# Function Name: `ToBinary`

## Description
 Calculates the binary representation of Base64-encoded data.

## Return Type
`binary`

## Syntax
```cfml
toBinary(base64_or_object)
```

## Arguments

### Argument: `base64_or_object`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A string or a variable that contains one:
 * In Base64 format to convert to binary
 * In binary format to test whether it is valid
