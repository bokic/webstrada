# Tag Name: `cfassociate`

## Description
Allows subtag data to be saved with a base tag. Applies only
 to custom tags.

## Syntax
```cfml
<cfassociate basetag="">
```

## Attributes / Variants

### Attribute: `basetag`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Base tag name

### Attribute: `datacollection`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: Structure in which base tag stores subtag data

## Limitations

- **Must be nested inside**: *None*
- **Must not be nested inside**: *None*
