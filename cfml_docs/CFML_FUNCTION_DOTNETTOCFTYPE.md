# Function Name: `DotNetToCFType`

## Description
Explicitly converts a value returned by a .NET method to the corresponding ColdFusion data type.

## Return Type
`any`

## Syntax
```cfml
dotnetToCFType(variableName)
```

## Arguments

### Argument: `variableName`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Name of the .NET variable to convert.

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `8`.
