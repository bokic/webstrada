# Function Name: `FileReadLine`

## Description
Returns the next line from the file

## Return Type
`string`

## Syntax
```cfml
fileReadLine(file)
```

## Arguments

### Argument: `file`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: file object previously opened with fileOpen()

## Limitations and Other Info

- **Permission/IO**: Requires appropriate file system read/write permissions on the target directory/path.
- **Related Functions**: `fileOpen`, `fileClose`, `fileIsEOF`, `fileRead`, `fileWrite`
