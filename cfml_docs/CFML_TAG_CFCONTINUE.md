# Tag Name: `cfcontinue`

## Description
Used within a cfloop tag. Skips processing the remainder of the loop iteration, and continues on to the next iteration.

## Syntax
```cfml
<cfcontinue>
```

## Attributes / Variants

This tag does not have any attributes or parameters.

## Limitations

- **Must be nested inside**: `cfloop`
- **Must not be nested inside**: *None*
