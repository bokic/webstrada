# Function Name: `FormatBaseN`

## Description
Converts number to a string, in the base specified by radix.

## Return Type
`string`

## Syntax
```cfml
formatBaseN(number, radix)
```

## Arguments

### Argument: `number`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The number to convert

### Argument: `radix`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The base radix to use
