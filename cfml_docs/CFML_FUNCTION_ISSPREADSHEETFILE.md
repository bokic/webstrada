# Function Name: `IsSpreadsheetFile`

## Description
Checks if the input is a spreadsheet file or not

## Return Type
`boolean`

## Syntax
```cfml
isSpreadsheetFile(value)
```

## Arguments

### Argument: `value`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: A file path

## Limitations and Other Info

- **Related Functions**: `isPDFFile`, `isPDFObject`, `isSpreadsheetObject`
- **Coldfusion Support**: Minimum version: `9`.
