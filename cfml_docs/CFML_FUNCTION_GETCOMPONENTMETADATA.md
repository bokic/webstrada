# Function Name: `GetComponentMetaData`

## Description
Gets metadata (such as the functions and implemented interfaces of a component) for a CFC or ColdFusion interface.

## Return Type
`struct`

## Syntax
```cfml
getComponentMetadata(path)
```

## Arguments

### Argument: `path`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The dot-delimited path of the interface or CFC definition.
