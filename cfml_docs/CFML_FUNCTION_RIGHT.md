# Function Name: `Right`

## Description
 Gets a specified number of characters from a string,
 beginning at the right.

## Return Type
`string`

## Syntax
```cfml
right(String, count)
```

## Arguments

### Argument: `String`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: 

### Argument: `count`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: An integer or a variable that contains one.
 Number of characters to return.

- **Related Functions**: `left`, `mid`
