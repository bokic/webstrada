# Function Name: `CreateODBCTime`

## Description
Creates an ODBC time object.

## Return Type
`date`

## Syntax
```cfml
createODBCTime(date)
```

## Arguments

### Argument: `date`
- **Type**: `date`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Date or date/time object.
