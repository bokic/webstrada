# Function Name: `ImageMakeTranslucent`

## Description
 Create a new translucent image with given percentage of translucence.

## Return Type
`any`

## Syntax
```cfml
imageMakeTranslucent (img, percent__);
```

## Arguments

### Argument: `img`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The ColdFusion image on which this operation is performed.

### Argument: `percentage`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The percent of translucence: 0 = opaque, 100=transparent. Decimal values are supported

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `10`.
