# Function Name: `Chr`

## Description
Converts a numeric value to a UCS-2 character.

## Return Type
`string`

## Syntax
```cfml
chr(number)
```

## Arguments

### Argument: `number`
- **Type**: `numeric`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The UCS-2 code value (a number in the range 0 - 65535)
