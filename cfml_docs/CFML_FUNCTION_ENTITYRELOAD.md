# Function Name: `EntityReload`

## Description
Reloads data for an entity that is already loaded.

## Return Type
`void`

## Syntax
```cfml
entityReload(entity)
```

## Arguments

### Argument: `entity`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Name of the entity to be reloaded
