# Function Name: `IsValidOauthAccesstoken`

## Description
Checks if the OAuth access token is still valid.

## Return Type
`boolean`

## Syntax
```cfml
isValidOauthAccesstoken(token,type);
```

## Arguments

### Argument: `token`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The access token to check.

### Argument: `type`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The type of the OAuth server (facebook/google).

## Limitations and Other Info

- **Coldfusion Support**: Minimum version: `11`.
