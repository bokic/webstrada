# Function Name: `SpreadsheetSetFooter`

## Description
 Adds a footer to the specified worksheet.

## Return Type
`void`

## Syntax
```cfml
spreadsheetSetFooter(spreadsheetObj, leftFooter, centerFooter, rightFooter)
```

## Arguments

### Argument: `spreadsheetObj`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The Excel spreadsheet object to which to add the footer.

### Argument: `leftFooter`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Adds the footer in the left side of the worksheet.

### Argument: `centerFooter`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Adds the footer in the center of the worksheet.

### Argument: `rightFooter`
- **Type**: `string`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Adds the footer in the right side of the worksheet.
