# Function Name: `ObjectSave`

## Description
Serialize object to file or convert it to binary format

## Return Type
`binary`

## Syntax
```cfml
objectSave(object [, file])
```

## Arguments

### Argument: `object`
- **Type**: `variableName`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Object to be serialized

### Argument: `file`
- **Type**: `string`
- **Required**: Optional
- **Default Value**: *None*
- **Description**: File in which serialized object will be stored
