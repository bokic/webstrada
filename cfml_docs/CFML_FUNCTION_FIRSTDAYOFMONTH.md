# Function Name: `FirstDayOfMonth`

## Description
Determines the ordinal (day number, in the year) of the first day of the month in which a given date falls.

## Return Type
`numeric`

## Syntax
```cfml
firstDayOfMonth(date)
```

## Arguments

### Argument: `date`
- **Type**: `date`
- **Required**: Required
- **Default Value**: *None*
- **Description**: Date or date/time object.
