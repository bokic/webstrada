# Function Name: `IsImage`

## Description
Determines whether a variable returns a ColdFusion image.

## Return Type
`boolean`

## Syntax
```cfml
isImage(value)
```

## Arguments

### Argument: `value`
- **Type**: `any`
- **Required**: Required
- **Default Value**: *None*
- **Description**: The value that is checked.
